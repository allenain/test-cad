# Test Project — Frontend + Backend (Contact Form)

Этот проект — решение тестового задания: адаптивный двухстраничный сайт с формой обратной связи и backend-обработкой данных.

## Просмотр проекта

Проект доступен по [ссылке](https://test-cad.onrender.com/)

##  Стек технологий

- [Next.js](https://nextjs.org/) — SSR + API routes
- [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/) — валидация формы
- [Material UI](https://mui.com/) — компоненты UI
- [Styled Components](https://styled-components.com/) — стилизация и переменные темы
- [Render](https://render.com/) — деплой и backend-хостинг
